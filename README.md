# Dungeon-Crawler-Py 🏰

A lightweight Python prototype exploring procedural dungeon layout generation, spatial geometry, and coordinate line rendering.

### 🎯 Technical Objectives
* **Coordinate & Line Geometry:** Algorithmic rendering of walls, corridors, and room boundaries.
* **Modular Architecture:** Clean separation of rendering routines and spatial logic (`importing.py`).
* **Iterative Game Prototyping:** Core structural foundation for upcoming 2D dungeon crawler mechanics.

### 🚀 Getting Started
```bash
git clone [https://github.com/tsiphone/dungeonpy.git](https://github.com/tsiphone/dungeonpy.git)
cd dungeonpy
python importing.py
